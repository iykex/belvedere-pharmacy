## 1. PROJECT OVERVIEW

Belvedere Pharmacy operates **three branches** (Belvedere, Kidbrook, Lowfield).
This project aims to unify and modernize their digital ecosystem, ensuring:
● Professional web presence for all branches
● Centralized analytics and oversight
● Seamless integration with the Charac - NHS services platform
● Improved patient experience
● Ownership and independence from external developers
● Scalable foundation for future e-commerce

## 2. PROJECT OBJECTIVES

### Objective 1 — Build Three Modern Pharmacy Websites

Develop brand-aligned, fast, secure, and mobile-friendly websites for:

1. Belvedere Pharmacy
2. Kidbrook Pharmacy
3. Lowfield Pharmacy

Each website will include:
● Homepage with clear service offerings
● NHS-accredited services with pictorial icons
● Prescription ordering & appointment booking via Charac links
● Consultation request form (sent directly to pharmacy email)
● Testimonials from Google reviews
● Newsletter subscription system
● FAQ, Contact, Opening Hours pages
● Cookie, Privacy & Terms pages (GDPR-compliant)
● Social media integration
● Branch selector and cross-branch linking
● Improved color branding and typography

### Objective 2 — Build a Central Multi-Branch Dashboard

A secure admin dashboard to allow management to:
● View analytics across all three branches
● See consultation form submissions
● Track newsletter signups
● View user activity metrics
● Switch between branch dashboards
● Track cookie consent data
● Prepare for future e-commerce and inventory modules

### Objective 3 — Integrate With Charac Platform

Since Charac does not currently provide APIs, integration will be via:
● Secure redirect links
● Login page redirection
● Appointment & prescription ordering redirection
● App download links
● Deep link support if made available in future
Additionally:
● Official request to Charac for API confirmation
● Obtain pharmacy IDs & branch identifiers

```
● Document integration process for future scalability
```

### Objective 4 — Transfer Full Website Ownership From Old Developers

Belvedere will obtain complete control of:
● Domains & DNS
● Hosting accounts
● Website source code
● CMS logins
● Backups and data
● SSL certificates
● Third-party integrations
Once transferred, the internal team will maintain and update everything.

### Objective 5 — Social Media Setup & Content Framework

Create official:
● Facebook Page
● Instagram Page
● TikTok
● LinkedIn
Responsibilities:
● Establish branding consistency
● Connect socials to the websites
● Define posting frequency and templates
● Assign ongoing management to internal comms/content team

### Objective 6 — Future Phase (Not in Current 8-Week Build): E-Commerce

Foundational planning for:
● Online sales of OTC products
● Payment integration (Stripe/Paystack)

● Delivery & Click & Collect modules
● Inventory & order management dashboard
This will be a separate project phase after initial launch.
